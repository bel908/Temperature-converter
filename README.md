# Temperature Converter 🌡️

A simple web app built with HTML, CSS, and JavaScript that converts temperatures between Celsius, Fahrenheit, and Kelvin. Includes input validation and absolute zero error handling.

---

## 🚀 Features
- Convert between Celsius, Fahrenheit, and Kelvin
- Input validation with error messages
- Absolute zero logic (no values below -273.15 °C)
- Responsive design for desktop and mobile
- Clean, beginner-friendly UI

---

## 📦 Usage
1. Enter a temperature value.
2. Select the unit (Celsius, Fahrenheit, or Kelvin).
3. Click "Convert" to see results in all units.
